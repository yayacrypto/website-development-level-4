# Solutions

Try each bug yourself first.

1. **Broken image.** Network tab shows a 404 for `herro.png`. Fix the typo in `bugs.html`: `../assets/hero.png`.
2. **Console error.** Clicking the button logs `ReferenceError: count is not defined`. In `bugs.js`, use `clicks` instead of `count`.
3. **Sideways scrolling.** In the Elements panel, the `.wide-box` has a fixed `width: 900px`. In `practice.css`, replace it with `max-width: 100%` (and remove `max-width: none`).
